# Catalogue history data

This directory is generated by the catalogue history workflow.

- `index.json` lists available snapshots and their change sets.
- `snapshots/` contains immutable, complete catalogue snapshots.
- `changes/` contains deterministic record-level differences between consecutive snapshots.

See [the catalogue history documentation](../../../docs/catalogue-history.md) for the format, validation rules, timestamp handling, corrections and retention policy. Do not edit generated history files manually; update the current catalogue through the normal reviewed data process and let the workflow capture it.
