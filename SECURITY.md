# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch. There are currently no separately maintained release branches.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting for this repository where available:

https://github.com/thewilferine/compute-ledger/security/advisories/new

If private vulnerability reporting is unavailable, contact the maintainer privately through their GitHub profile:

https://github.com/thewilferine

Please include:

- A description of the affected component and the potential impact.
- Steps to reproduce the issue or a proof of concept, where safe.
- Any relevant versions, commits, logs, or screenshots.
- Suggested mitigations, if you have them.

Please allow a reasonable amount of time for investigation and a fix before making details public. The maintainer will acknowledge the report and coordinate any disclosure.
